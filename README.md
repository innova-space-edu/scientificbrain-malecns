# ScientificBrain MaleCNS

Experimental biological core for Scientific Brain using the male Drosophila
connectome.

The current reference notebook is preserved at:

notebooks/modelo_ia_m.ipynb

Development of the new simulation layer is occurring on the
bioengine-v1-colab branch. BioEngine is compatibility-first: it must reproduce
the historical MaleCNS reservoir before adding neuromodulation, eligibility
traces, plasticity budgets or consolidation.

See docs/BIOENGINE_V1.md.
